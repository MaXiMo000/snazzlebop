# Jump-scare photos

Drop `.jpg`, `.jpeg`, `.png` or `.webp` files here and rebuild. Every photo in this folder joins the
rotation (bundled with the app, served from our own origin, so the CSP stays `'self'`). With no photos
here, the scare falls back to the ghosts drawn in code.

Only add images you have the right to use: your own photos, or ones with a licence that allows
reuse (e.g. CC0 / public domain, Pexels or Pixabay licence). The repo is public.

Tall, face-centred photos work best: they fill a phone screen edge to edge.
